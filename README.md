## DND server (multiplayer dungeon platform)

This repo contains a Godot-based, small-scale (~5 players) multiplayer “Doomlike” dungeon platform for D&D sessions.

### Repo layout
- `docs/`: MVP spec, protocol notes, hosting notes.
- `client/`: Godot project for the desktop client.
- `server/`: Godot project for the headless server (authoritative sim).
- `shared/`: shared schemas and reference docs (language-agnostic).

### Status
Early development. Start with `docs/mvp.md` and `docs/protocol.md`.
